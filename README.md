# Roamly-Travel-Website
## Overview
Roamly is a travel website created as part of a university web development course. The project focuses on presenting travel-related information through a visually organized, user-friendly interface.

The design features a navigation header, a travel-themed hero section, content cards, reservation form, an events calendar, and a structured footer.

**Please see screenshots of the website in the roamly-travel-website-screenshots file.
## Features
- Fixed navigation header for easy access to site sections
- Travel-themed hero section and visual hierarchy
- Card-based content layout
- User input form
- Calendar layout
- Structured footer with multiple columns
- Consistent styling, spacing, and color choices

## Technologies
- HTML
- CSS

## What I Learned
This project helped me practice structuring a multi-section webpage, applying CSS to create a cohesive visual design, and organizing content for usability. It also gave me experience translating a design concept into a website.

## Project Access
This project was completed as part of a university course. In accordance with the course's project-sharing restrictions, this public repository only contains screenshots and a project description. However, the source code and website link is maintained in a private repository and may be accessed by interviewers upon request.
